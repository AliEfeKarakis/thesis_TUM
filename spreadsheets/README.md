This directory contains Excel exports of the Google Sheets spreadsheets generated during the 120 included regular executions documented in the "Evaluation" chapter of the thesis.
Each file corresponds to one execution and contains the two worksheet tabs belonging to that workflow.

- S1–S3: Spreadsheet Order Filtering
- I1–I3: Invoice Registration
- V1–V3: Vendor Onboarding and Ticket Processing
- T1–T3: Travel Authorization Request Processing

Each scenario contains 10 executions. Filenames identify the scenario and run number.
For example, `S1_run_01.xlsx` corresponds to the first included execution of scenario S1.
These files contain generated spreadsheet results.
They are not input files required to run the workflows.
Execution logs provide the corresponding process-execution evidence.
