This directory contains three execution logs for each error-handling case: E1, E2, E3, and E4, for a total of 12 error-handling tests.

These tests were conducted separately from the 120 included regular executions. The “Evaluation” chapter describes the case-specific requirements and the observed results.

For information about the replacement of actual backend API-key values and the preservation of the intentionally invalid API-key value in E2, see the [execution-log README](../README.md).
