This directory contains the logs of the 120 included regular executions, organized by workflow and scenario.

- S1–S3: Spreadsheet Order Filtering
- I1–I3: Invoice Registration
- V1–V3: Vendor Onboarding and Ticket Processing
- T1–T3: Travel Authorization Request Processing

Each scenario contains 10 execution logs.

See the [execution-log README](../README.md) for information about the replacement of backend API-key values for publication.
